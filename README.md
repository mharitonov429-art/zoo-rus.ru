# Зоо-Месягутово (zoo-rus.ru)

Неофициальный справочник по ветеринарии Месягутово и Дуванского района. Статический сайт без зависимостей: генератор `build.mjs` (Node.js 18+) собирает чистые HTML-файлы в папку `dist/`. Весь важный контент лежит в HTML, JavaScript нужен только для счётчика Метрики, плашки cookie и подсказок для ИИ-агентов (`webmcp.js`).

## Быстрый запуск на GitHub Pages

1. Создайте на GitHub репозиторий (для бесплатного тарифа он должен быть **публичным**) и загрузите в него содержимое этого архива так, чтобы в корне репозитория лежали `build.mjs`, `data/`, `content/` и папка `.github/`. Основная ветка называется `main`.
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. Там же, в поле **Custom domain**, впишите `zoo-rus.ru` и сохраните (домен добавляйте **до** настройки DNS). Включите **Enforce HTTPS**, когда она станет доступна.
4. У регистратора домена создайте DNS-записи:
   - четыре записи **A** для `zoo-rus.ru`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись **CNAME** для `www`: `<ваш-аккаунт>.github.io`.
   Актуальные адреса сверьте с документацией GitHub Pages («Managing a custom domain»).
5. Первый запуск: вкладка **Actions → build-and-deploy → Run workflow**. Сайт появится на `https://zoo-rus.ru/` через несколько минут.

Сборка запускается сама: при каждом изменении в `main` и раз в сутки (в 03:00 UTC). Если защита ветки `main` запрещает боту записывать файл `data/rotation-state.json`, разрешите это в настройках защиты или отключите запись (тогда ротация ссылок будет «сбрасываться»).

## После запуска (чек-лист)

1. Откройте `https://zoo-rus.ru/googled005414cfdf84903.html` и `https://zoo-rus.ru/yandex_82c6400a99edc483.html`, затем нажмите «Подтвердить» в **Google Search Console** и **Яндекс Вебмастере**. Проверьте, что имя файла Яндекса совпадает с тем, что показывает Вебмастер. Если нет, переименуйте файл в папке `static/`.
2. Добавьте `https://zoo-rus.ru/sitemap.xml` в оба сервиса. В Вебмастере укажите регион: Республика Башкортостан.
3. В Яндекс Метрике (счётчик 114168885) создайте цели по идентификаторам JavaScript-события: `call_stanciya`, `call_aravet`, `call_ads`, `mail_ads`, `order_click`.
4. Заведите или проверьте карточки в Яндекс Бизнесе, 2ГИС и Google Business для организаций, которые вы представляете.
5. Проверьте сайт в PageSpeed Insights и валидаторе разметки (validator.schema.org).
6. Юридическая проверка: политику конфиденциальности (`/politika-konfidencialnosti/`) и плашку cookie желательно показать юристу, поскольку Метрика с «Вебвизором» собирает данные посетителей.

## Как добавлять материалы

**Новость.** Создайте файл `content/novosti/<адрес-латиницей>.md` по образцу `otkryt-spravochnik-zoo-meshyagutovo.md`. Поля в шапке: `title`, `description`, `date`, по желанию `updated` и `answer`.

**Статья.** Скопируйте `content/stati/_template.md` в `content/stati/<адрес-латиницей>.md`, заполните шапку (`category` латиницей, например `koshki`) и текст. Файлы, начинающиеся с `_`, в сайт не попадают. Адрес статьи: `/stati/<category>/<адрес>/`. Пока в `content/stati/` нет статей, раздел `/stati/` закрыт от индексации.

**Товары.** В `data/products.json` 20 заготовок. Чтобы товар появился, заполните `name`, `description`, `brand`, `specs` (список пар «название», «значение») и поставьте `"published": true`. Цены не выводятся, пока вы их не добавите в описание. Пока нет ни одного опубликованного товара, витрина закрыта от индексации. Заказ принимается по телефону из `data/site.json` (`orderPhone`) и по почте.

**Продавцы птицы.** Добавляйте объекты `{"name": "...", "what": "...", "phone": "..."}` в `data/poultry-sellers.json`, только с согласия продавцов.

**Организации и соседние районы.** Данные лежат в `data/organizations.json`, `data/neighbors.json`, `data/big-clinics.json`. Меняйте значения там: страницы, файл `webmcp.js` и поисковый индекс обновятся при сборке. После проверки обновите дату в `data/site.json` (`verified`).

**Адрес и контакты владельца.** `data/site.json`. Чтобы показать ИНН на странице «Контакты», впишите его в `owner.inn` и поставьте `owner.showInn: true`.

## Локальный просмотр

```
node build.mjs        # собрать
node scripts/check.mjs  # проверить ссылки, H1, canonical, разметку
node scripts/serve.mjs  # открыть http://localhost:8080
```

## Что делает ротация ссылок на главной

Перед подвалом главной страницы выводятся секции со ссылками (до 10 в секции). Раз в сутки (по расписанию GitHub Actions) набор сдвигается: показанные ссылки уходят в конец очереди, новые страницы встают первыми. Статический сайт не знает, заходил ли бот, поэтому ротация идёт по расписанию. Пока страниц мало, блок показывает почти все. Состояние очереди хранится в `data/rotation-state.json`.

## Ограничения

- Формы на сайте не используются (закон о хранении персональных данных в России): заказы идут по телефону и почте.
- `llms.txt`, `ai-catalog.json` и `webmcp.js` нужны «не навредит»: документальных подтверждений, что поисковики их учитывают, нет. WebMCP это черновик стандарта.
- Данные о соседних районах и клиниках Уфы взяты из открытых источников и справочников на дату проверки (`verified` в `data/site.json`) и могут устаревать.
